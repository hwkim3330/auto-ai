## ⚖️ 3. 한국 AI 관련 법률 및 규제

### 3.1 데이터 관련 법률

#### **개인정보보호법 (Personal Information Protection Act)**
- **핵심 내용**:
  - 개인정보 수집/이용 동의 필수
  - CCTV 영상은 **개인정보**로 간주
  - 영상 보관 기간 제한 (일반적으로 30일)
  - 개인 식별 시 반드시 고지 필요
  
- **Vision Pro 시스템 적용**:
  - ✅ **익명화 필수**: 얼굴 모자이크 처리
  - ✅ **동의 고지**: 촬영 사실 명확히 표시
  - ✅ **보관 기간**: 로그 30일 이내 삭제
  - ✅ **목적 제한**: 보안/모니터링 외 사용 금지

#### **영상정보처리기기법 (CCTV Law)**
- **핵심**:
  - CCTV 설치 시 사전 신고
  - 촬영 범위 최소화
  - "CCTV 작동중" 안내판 필수
  
- **Vision Pro 적용**:
  - 상업용 사용 시 법적 검토 필요
  - 공공장소 사용 시 허가 필요

#### **데이터3법 (Data 3 Laws)**
1. **개인정보보호법**
2. **정보통신망법**
3. **신용정보법**

- **가명정보 활용 허용**: AI 학습 데이터로 활용 가능
- **데이터 결합 허용**: 특정 기관을 통한 데이터 결합

- **학습 능력**: 새로운 환경에 적응

- ✅ **3D 인식**: Depth Estimation으로 이미 공간 파악
- ✅ **객체 이해**: YOLO로 80개 클래스 인식
- ✅ **공간 지도**: BEV로 top-down 시각화
- ❌ **추론/계획**: 현재 없음 → 추가 필요
- ❌ **언어 이해**: 현재 없음 → LLM 통합 필요

### 9.6 구현 예시: "지능형 경비 에이전트"

#### 시나리오: 아파트 단지 24시간 무인 감시

```
시스템 구성:
├─ 카메라 10대 (CCTV)
├─ Edge AI 서버 (Vision Pro Agent)
└─ 관제실 대시보드

에이전트 능력:
1. 상시 모니터링
   - 10개 카메라 동시 분석

   - 3D 공간 맵 생성

2. 이상 감지
   - 야간 침입: "밤 10시 이후 외부인 감지"
   - 쓰레기 불법 투기: "쓰레기 버리는 행동 인식"
   - 주차 위반: "장시간 정차 차량 감지"

3. 자동 대응
   - 관제실 알림: "북문에서 의심 행동 감지"
   - 음성 경고: "CCTV 녹화 중입니다"
   - 자동 신고: 119/112 자동 연결 (옵션)

4. 보고서 생성
   - 일일 요약: "오늘 방문자 327명, 차량 189대"
   - 주간 트렌드: "목요일 저녁 가장 혼잡"
   - 이상 징후: "최근 3일간 외부인 출입 증가"
```

#### 기대 효과
- **인건비 절감**: 경비원 3명 → 1명 (야간 무인 운영)
- **대응 속도**: 이상 감지 즉시 알림 (<5초)
- **기록 관리**: 자동 로그, 검색 용이
